## Empresa

**El Manglar** es un restaurante costero ubicado en el Malecón 2000, Guayaquil, especializado en ceviches, encebollado y mariscos frescos preparados con producto comprado a diario a pescadores artesanales.

## Objetivo del sitio

Presentar la identidad de El Manglar, su historia, su menú y sus datos de contacto a través de un sitio informativo de cinco páginas, desarrollado únicamente con HTML5 y CSS3, y desplegado en Microsoft Azure App Service.

## Tecnologías utilizadas

- HTML5 semántico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 (Flexbox, CSS Grid, variables CSS, media queries, pseudoclases `:hover`/`:focus-visible`)
- Sin frameworks, sin JavaScript, sin plantillas descargadas
